设计说明（评审 → 重构）
1. 整页从浅灰后台卡片 → 深空多层底 + 数据链路动画 + 玻璃卡，与两块大屏视觉气质打通，入口即"有内味儿"。
2. 缩略预览从静态占位 → 仿真大屏截图并带扫描光带 / 订单流滚动 / 环形旋转 / 柱状呼吸动效，一眼看出大屏长什么样。
3. 页头补 数据源在线状态 + 实时时钟，配得上"大数据中心"之名（时钟为示意，重构时接真实时间）。
4. 名称设置从平铺弱区 → 玻璃面板，图标+主次分明；卡片整块可点 + 悬浮"打开大屏"遮罩，热区不再与底部按钮打架。
5. 卡片用 auto-fit 网格，未来加大屏（如"财务大屏"）会自动换行、不失衡。
